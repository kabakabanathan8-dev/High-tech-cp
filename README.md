# CONTREPOIDSTECH — Site vitrine

Site statique responsive en HTML, CSS et JavaScript, prêt à être publié sur GitHub Pages ou Vercel.

## Fichiers
- `index.html` : accueil
- `services.html` : présentation des 9 domaines de services
- `portfolio.html` : galerie filtrable de démonstration
- `contact.html` : formulaire qui prépare une demande WhatsApp
- `css/style.css` : design et responsive
- `js/main.js` : menu mobile, animations, filtres et formulaire

## Tester
Ouvrir `index.html` dans un navigateur. Une connexion Internet est nécessaire pour charger les polices Google et les photos distantes utilisées dans les zones visuelles.

## Déployer sur Vercel
1. Extraire le ZIP.
2. Envoyer le contenu du dossier dans un dépôt GitHub.
3. Dans Vercel, choisir **Add New → Project**.
4. Importer le dépôt GitHub.
5. Laisser le framework sur **Other** et les champs de build vides.
6. Cliquer sur **Deploy**.
